Big outline-stroke pillar word with a roman numeral and a description — the "Kultur / Liv / Språk" rows. The word is outlined and fills with its colour on hover.

```jsx
<Pillar numeral="i." word="Kultur" color="var(--hs-amarillo)">
  Skikkene, festene, maten og alt det ingen forteller deg.
</Pillar>
<Pillar numeral="ii." word="Liv" color="var(--hs-azul)">Hvordan det egentlig er å leve i Spania.</Pillar>
<Pillar numeral="iii." word="Språk" color="var(--hs-rojo)">Spansk som faktisk brukes.</Pillar>
```

- Stack pillars; the last one's bottom border can be removed via `style`.
- Use the núcleo trio (amarillo / azul / rojo) across the three pillars.
